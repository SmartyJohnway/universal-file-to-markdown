# Maintainers

## Current maintainer

## Responsibilities

Maintainer responsibilities include:

- triaging issues and pull requests;
- reviewing converter correctness and regression evidence;
- preserving schema and bundle-contract integrity;
- approving releases and tags;
- coordinating vulnerability response;
- maintaining project governance and community standards.

See `GOVERNANCE.md`, `CONTRIBUTING.md`, `SECURITY.md`, and `RELEASING.md` for the applicable policies.
