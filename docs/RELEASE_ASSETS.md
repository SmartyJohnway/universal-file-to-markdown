# Release Assets

A tagged release should provide or link to:

1. GitHub-generated source archives.
2. A clean release ZIP and Agent Skill ZIP generated by
   `.github/workflows/release-package.yml`.
3. A SHA-256 checksum file for each ZIP and the release-package manifest.
4. The version-specific `RELEASE_NOTES_vX.Y.Z.md` as the release description.
5. `LICENSE`, `THIRD_PARTY_NOTICES.md`, and citation metadata inside the source archive.

The clean skill ZIP intentionally excludes repository-only infrastructure such as `.git`, `.github`, local caches, virtual environments, and private fixtures.

Before attaching an artifact to a GitHub Release, verify its checksum and inspect the archive listing.
