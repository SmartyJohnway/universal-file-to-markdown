# Roadmap

This roadmap is directional and does not promise delivery dates.

## Current release line: 1.6.x

Focus:

- release hardening;
- real-world integration fixtures;
- validator and provenance correctness;
- documentation, security, and packaging quality;
- backward-compatible schema 1.0 improvements.

## Candidate next steps

- richer PDF and scanned-table region segmentation;
- improved DOCX tracked-change, nested-table, and image anchoring support;
- deeper Excel chart and dashboard metadata;
- optional Tier-2 escalation profiles for heavier parsers;
- benchmark corpus and semantic quality scoring;
- reproducible container images and locked dependency sets;
- machine-readable engine capability and warning catalogs.

## Out of scope unless explicitly reconsidered

- executing Office macros or embedded active content;
- replacing malware scanning or sandboxing;
- guaranteed visual round-trip reconstruction;
- directly parsing legacy binary `.doc`, `.xls`, and `.ppt` without conversion;
- silently hiding low-confidence or unsupported structures.

Roadmap proposals should be opened as focused feature requests with measurable acceptance criteria.
