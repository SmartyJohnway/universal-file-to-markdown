Subject to the license terms, users may use, modify, reproduce, distribute, sublicense, and commercially use the project.

## Main obligations

When redistributing the project or a derivative work:

- include a copy of the Apache License 2.0;
- preserve applicable copyright, patent, trademark, and attribution notices;
- mark modified files with prominent notices;
- preserve a project NOTICE file if one is included in a future release.

Apache-2.0 also includes an express patent grant from contributors for claims necessarily infringed by their contributions, subject to the license terms.

## Dependencies and documents

Runtime dependencies remain under their own licenses. The project license does not grant rights to source documents processed by the software. Users must have appropriate rights to process, store, transform, and redistribute each input and output document.
