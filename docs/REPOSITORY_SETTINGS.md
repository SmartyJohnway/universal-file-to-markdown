# Recommended GitHub Repository Settings

These settings require repository-administrator action in GitHub and are not fully represented by tracked files.

## General

- Default branch: `main`
- Enable Issues
- Enable Discussions if community Q&A is desired
- Disable wiki unless it will be maintained
- Enable automatically delete head branches after pull requests are merged

## Pull requests

- Prefer squash merging for focused history
- Allow maintainers to update pull-request branches
- Require conversation resolution before merge

## Branch protection for `main`

Recommended required checks:

- `test / pytest`
- `CodeQL / Analyze Python`
- `Dependency review / dependency-review`
- `Validate repository metadata / validate`
- `Markdown links / check-links`

Also recommended:

- require a pull request before merging;
- require branches to be up to date before merging;
- block force pushes and branch deletion;
- require signed commits only if the maintainer can consistently support that workflow.

## Security

- Enable private vulnerability reporting
- Enable Dependabot alerts and security updates
- Enable secret scanning and push protection where available
- Review CodeQL alerts before release

## Releases

- Create annotated tags from verified `main` commits
- Attach the clean ZIP and SHA-256 checksum generated by the release-package workflow
- Use generated release notes as a starting point and review them against `CHANGELOG.md`
